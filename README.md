# 标签重构工具 v4.0

把「标签」从图纸到成品表这一整条链做成**可复现**：数据工具读懂没见过的图纸、自动出 NOTE 表头表；设计器用四层模型把 NOTE 值填回标签版式 —— **换规格只换数据，不动版式**。

## 为什么做

原来两件事分开做：桌面数据工具按图纸出 NOTE 表头表，一套图纸配一份 profile 说明书；标签版式则靠 BarTender 人工画。图纸一换，说明书要重做、版式也要重画。

三个核心痛点：

1. **新图纸没有说明书只能出半成品草稿**
2. **版式和数据两张皮**，改一处要两头对
3. **同一份图纸的写法千变万化** —— `Ø` / `Æ`、全角括号、中英混排表头、图纸把 `SERIAL` 拼成 `SEARAL`，某一处没接住就整列失效、界面上还看不出来。这是最贵的错。

## 这个仓库里有什么 / 没有什么

只放**源码**（`app/`）与启动器。

- **没有 `runtime/`**：完整发布包自带 Python 运行时（181 MB）与离线 wheels（27 MB），超过 GitHub 单文件限制，也不该进版本库
- **没有 `data/`**（93 MB）：模板库、素材、图库、基准叠影、技能库学习记录，均为运行期数据
- **没有具体产品的模板定义与操作手册**：模板是按客户图纸生成的，属客户资料，不随代码公开。仓库只提供**引擎与设计器**，模板需自行建
- **没有 `dev/`**：调试脚本与矢量化工具

## 两条腿

### 数据侧：规则文字 → NOTE 表头表

规则文字（txt/md）＋ TABLE 1/2/3 进，一个 xlsx 出：NOTE 位号当表头，另附 TABLE 原表与「表头对照」说明表（每列写清取自哪列、怎么算、为什么留空）。

- **没见过的新图纸也能跑**：自动认条码位、字段位、组合串、压力档、爆破压力区间、固定文字、图版位、ITEM 矩阵；认不出的留空、不猜
- **三档整列底色**：蓝＝确实该留空、黄＝没把握、无色＝已取到
- **一条 NOTE 两个值**时自动按值拆成两份表
- **防错三件**：输入体检（表名 / 表头重名 / 空行 / 直径与列头对不上 / GS1 校验位 / 字段一对多 / 数值列混文字）、取不到原因点名、基准回归 + 写法变体

### 版式侧：四层模型

| 层 | 内容 | 约束 |
|---|---|---|
| **L1 底图** | 空白图纸 PDF | 换 PDF 自动按页面真实毫米定画布 |
| **L2 图形** | 矢量图库取图 + 矢量色块 | 只画矢量，不画彩色位图 |
| **L3 静态文字** | 品名、注册信息、标签词 | 所有规格一致 |
| **L4 数据文字** | `【NOTE 03】` 占位符 | 值来自数据表，与数据工具输出一一对应 |

每层只能编辑自己那层；NOTE 位号直接当占位符。

## 命令行接口（v4.0 新增）

`app/engine/ctl.py` 提供 7 个命令，全部 JSON 输出、不依赖 GUI，外部脚本或 AI 不打开界面也能操作模板：

```
list / get / set / place --snap / score / link --auto / export
```

改文件前自动备份。

## 几个关键实现

- **按叠影定宽**：由叠影墨迹框取字高与字宽，先定字号，再先摊词距后摊字距；实测墨迹宽误差 0.02mm（要求 ≤0.2mm），字形纵横比不变
- **字距 / 词距**：替代原来的横向拉伸（拉伸会把字压扁），旧模板的 `xs` 自动迁移为 `tracking`
- **画布边距**：画布 = 图片框 + 2×边距，原点仍是框外沿；预览、PNG/PDF 导出、批量 PDF、PDF 文字层坐标、验证裁剪全部走同一个函数取范围
- **L1 黑框检测**：用行/列投影的长直线判定图纸黑框（不用任意墨点，避免文字行被误判）；检不出就如实报告「没有黑框」
- **技能库学习记录**：每次对位 / 选图 / 链接被人工纠正时，追加一条「症状 / 原因 / 规则」；程序只自动生成「症状」，「原因」和「规则」必须人工给 —— 程序不编造判断
- **三段式摆位**：行投影 + 连通块切出墨块清单 → 元素与墨块一对一指派（避免多个元素抢同一块墨）→ 墨压墨精修；对称位置按行/列取中位数统一对齐

## 验收口径（重要）

**不只看整体分，要按分区达标。** 整体对齐率存在虚高 —— 判定带 3px（约 0.25mm）容差且双向计分，基本只反映墨迹总量、不反映位置。改为 8×4 分区逐块验收后，实测某模板整体 80.44% 而分区平均仅 24.92%（32 块中 31 块低于 60% 过线）。

**本项目当前状态：分区验收未达标，摆位框架已就绪但尚未接入界面跑完整轮。** 在分区全部达标之前，不应对外称「已对齐」。

## 已知限制

- 人工写死列数的老版式必须走定稿 profile
- 日期、批号、二维码这类工单数据整列留空（规格表里本来没有）
- 认不出的 NOTE 位留空标黄，待人指认
- 部分区域原稿是转曲矢量图，改用素材开关、默认留空，缺素材时界面黄字提示
- 顺应性数值仍无生成器
- 矢量图库「序号→标签位置」对照表未建，目前靠图纸标注人工指认
- 分组 / 解组、旋转、纯矢量 PDF 导出仍未做，导出仍是位图
- 无档案的新图纸走草稿模式，个别折行仍认不出，靠黄底交人补
